# デザインガイドライン

デザインの正は実装(`app/src/`)。本ファイルは方針とルールのみ。

## 方針

- UIの質が競争力の核。「リンクを踏んだ瞬間にInstagramと違う」という体験が重要
- 作品が大きく、余白を持って表示される
- 展覧会のタイトル・期間・場所などのメタ情報がきれいにまとまっている
- スマホで崩れない
- **団体 → 展覧会 → 作品**という基本階層を保つ。継続展だけは任意で **団体 → シリーズ → 各開催回 → 作品** とし、シリーズと個々の展覧会を混同させない
- 追加順の無限フィードではなく、利用者が「時間を遡る」「表現を渡る」のどちらへ進むか選べる構造にする

## 分野間の探索

- 主分野は入口であり、閲覧範囲を閉じる壁にしない。素材・技法、主題、視覚的特徴を横断キーとして別分野へ接続する
- 関連カードには「墨と余白でつながる」「線の動きでつながる」など理由を表示し、単なる「おすすめ」で済ませない
- 分野を色分けしない。選択中はテラコッタ、接続線や補助語は墨色・Goldの範囲で表し、作品画像よりUIを目立たせない
- 接続表現は巨大なネットワーク図ではなく、起点・接続理由・行き先を読み取れる短いレールを基本とする。ホバーだけに依存せず、タップとキーボードでも選択できること

## 時間・シリーズ・比較

- 年タイムラインは装飾ではなく移動手段。年/回次、現在地、前後の開催を明示し、任意の開催回へ直接移動できるようにする
- 長いシリーズでは全回を同じ密度で並べず、最新3回・節目・初回を先に見せ、利用者が全件を展開できるようにする
- モバイルで横長タイムライン全体を縮小しない。読める文字サイズと44px前後のタップ領域を保ち、横スクロールまたは縦の年代区切りへ変換する
- 比較UIは一度に2開催まで。代表作品を主役に、作品数・参加作家数・会場など同じ項目を同じ順序で並べる。推移グラフや数値の優劣を主役にしない
- 「前後回」「シリーズ全体」「同分野」「別分野」を区別し、どの方向へ移動するリンクかをラベルと配置で明示する

## カラーパレット(実装は `app/src/lib/tokens.js` の `T`)

ベースは**紙色・墨色**の2階調。アクセントは次の2系統に限定する。

| 役割 | 用途 | メモ |
|------|------|------|
| **Accent(テラコッタ)** | 主要 CTA、リンク強調、閉じる UI のアクセント枠 | `T.accent` / `T.accentInk` |
| **Gold(黄土〜金)** | ヘッダー/ナビの区切り、強調シャドウ、副バッジ | `T.gold` |

プレースホルダ背景などのムード色は**寒色(水色・紺の装飾)より暖色ベージュ**(`T.surfaceMuted`)を使う。装飾スポットが増えすぎないよう、ミント・すみれ等のサブカラーは基本追加しない。

## モバイル(情報密度・タップ)

- 一覧・ヘッダー・ボトムナビは、縦スペースを詰めつつ**主要タップ領域はおおまかに 44×44px 以上**(アイコンボタンは `minWidth` / `minHeight` で確保)
- 見出し・カード行のフォントはデスクトップより一段階小さくしてよい(例: 団体一覧タイトル 22px 前後)

## 外部リンク(団体ページ)

- 右上矢印だけにせず、**🔗 + ラベル + 下線付きホスト名**(またはカード左ボーダー)で「外部へ行くリンク」と分かるようにする
- 公開サイト内の内部リンクとは、`T.accent` の下線・左アクセントで差別化する
