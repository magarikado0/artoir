# プロダクト — コンセプト・ロードマップ・マネタイズ

> 最終更新: 2026-07-05(旧 `product/concept.md` / `product/roadmap.md` / `ops/monetization.md` を統合)

## コンセプト

展覧会ごとに作品をまとめて公開できるポータルサイト。

**建付けは「芸術(作品)のアーカイブ」**。展覧会なら何でも載せるのではなく、芸術作品に限る(作品が映える世界観が価値の中核のため)。機能・マネタイズのアイデアは「載るものが芸術作品か」を先に通す。

### Problem

InstagramなどのSNSは時系列フィードしかなく、「展覧会」という単位でコンテンツを整理できない。展覧会ごとにアカウントを作る運用は手間がかかる。Behanceはあくまで個人ポートフォリオ用で、複数人が参加した展覧会単位の整理には向いていない。

### Core Value

展覧会ページを作成してリンクを発行し、SNSで共有できる形にする。リンクを踏むと:

- UIが綺麗で作品が映える
- 展覧会ごとに作品がまとまって見られる
- その団体の過去・未来の展覧会一覧も見られる

SNSを置き換えるのではなく、**SNSで告知 → Artoirのリンクで詳細を見る**という共存設計。乗り換えコストがほぼゼロ。

## ロードマップ

### Phase 1 — MVP(〜2026年6月21日)✅ 完了

書道部の書展(2026-06-21)に合わせてリリース済み。団体ページ・展覧会ページ・作品表示・シェアリンク・閲覧ページ(UI重視)。

### Phase 2 — 認証・管理 ✅ 完了

ログイン(Google OAuth / メール+パスワード)、ダッシュボード(団体・個人)、団体・展覧会の編集・削除、プロフィール・作者紐づけ(artwork_creators)、お気に入り/コレクション。

### Phase 3 — マネタイズ(〜2027年度中を目標)

図録PDF生成の展覧会単位課金を本命とする(詳細は下記)。

- [ ] 図録PDF自動生成(表紙・目次・作品ページ・奥付)
- [ ] 展覧会単位の買い切り決済(Stripe決済リンク)
- [ ] 閲覧数アナリティクス
- [ ] 前提: 画像の元解像度保持(現状は長辺1920pxに圧縮しており印刷に不足)

## マネタイズ

### 方針(2026-07改訂)

主催者向けの月額サブスクは棚上げし、**図録PDF生成の展覧会単位課金**を本命とする。

- Web公開(展覧会ページ・作品掲載・シェアリンク)は**点数無制限・完全無料**
- 収益は「展覧会にすでに流れているお金(印刷費)の通り道になる」ことで得る

**なぜサブスクをやめるか**: サークルは年1〜2回しか展覧会をやらず、月額課金は支出構造に合わない(部費は「イベント単位」で支出される)。フリーミアムの一般的な転換率(2〜5%)では、目標有料数に対して母数が全く足りない。閲覧者とデータが増えるほど図録の価値が上がるため、無料側を制限する理由がない。

**なぜ図録か**: 図録づくりの本当の苦痛は印刷ではなく編集作業(数十点の作品画像・タイトル・キャプションの収集と組版)。Artoirは展覧会ページ作成の副産物としてこれを構造化済みなので、「展覧会ページを作ったら図録が出てくる」は他ツールで代替しにくい。

DM・作品ポストカードは検討の結果見送り(使うデータが少なく、Canvaやネット印刷直接入稿で代替可能なためArtoirの優位性がない)。

### 商品形態

**印刷は扱わず、入稿データ(PDF)の生成だけを売る。**

| 項目 | 内容 |
|------|------|
| 商品 | 展覧会ページから印刷用図録PDFを自動生成(表紙・目次・作品ページ・奥付) |
| 価格 | 1展覧会あたり2,000〜3,000円の買い切り(初回はモニター価格で検証) |
| 印刷 | 主催者自身がPDFをネット印刷(ラクスル・グラフィック等)に入稿 |
| 決済 | Stripeの決済リンク |

在庫・発送・印刷品質のクレームを抱えない。印刷発注の代行(マージン取得)は需要確認後の拡張とする。

### 検証計画

1. 京大書展(2026年6月)のデータから図録PDFを試作
2. 書道部に見せ、**次回展示で実額請求**して支払い意思を検証(「払うか聞く」は社交辞令になるため、実際に売る)
3. 秋の学祭シーズン(2026年11月)に他サークルへ「図録も作れます」で営業 — 試作と反応確認は夏中に完了させる

### 目標

- 有償図録で月1〜2万円のランニングコストを賄う
- 初期は赤字埋め程度と割り切り、不足分は助成金・学生起業支援の活用も検討する

### 長期方針(2026-08-19 メンバー合意・確定)

ビジネス実践ラボのアイデアシート(Notion「基礎講座① アイデアシート記入案」)としてメンバー間で合意した決定事項。

**サービスの一言定義**: 「展覧会を探して、残して、作品が買えるアートのポータルサイト」

**三本柱**(テーマの語順と対応):

- **残す**(無料・実運用中): 展覧会ページ作成・作品掲載・シェアリンク。作家と作品が蓄積される
- **探す**(無料): 近くで開催中の展覧会の検索・おすすめ機能で閲覧者を集める。学生展・小規模展の「今週末・近く」情報は未集約の空白地帯。ガイドマッチングは有料案から外し(無料展覧会に対価を払う動機が薄い)、この無料機能群の候補として検討
- **買える**(収益): 掲載作品に購入導線を付け、売れたときに手数料を得る。古美術屋案と海外販売案はこの一機能に統合

**顧客の定義**:

- 買う人: 作品を「飾って楽しむため」に買う個人。誰でも購入できる上で、特に有力な販売先は海外(米国など原画購入の習慣がある国。低価格帯〜$5,000の取引数が世界的に過去最多)
- 作家(=出品する人): 展覧会をArtoirに掲載している作家・学生団体・ギャラリー(掲載は無料)
- 古美術屋・美術商は顧客ではなく**売り先の開拓先(営業先)**という位置づけ

**探す機能の実装方針**: 京都圏に絞って開始し、検索機能の実装前に開催予定展の掲載密度を営業で作る(開いて数件出ないと二度と開かれない)。MVPは「開催中」タブ+都道府県フィルタで足りる(start/end_dateは既存、地域フィールドの追加のみ)

**コアの価値**: 「アーカイブの信用を販売の信頼に変換する」の一点。機能追加はここに寄与するかで判断する

**動機の公式ナラティブ**: 書道部として書展を運営する中で「すでに書道に興味がある人しか見に来ない」課題を経験 → 潜在的にアートに興味を持つ人に届けるためArtoirを開発(2026年6月リリース)→ その先の出口として販売。※「展覧会が消えるから」を起点として語るのは事実と異なるので不可

### 事業者クーポン提携(2026-08 検討中)

書遊Online運営の書道作品共有サイト「KAKOU」(投稿数に応じて書遊Onlineのクーポン付与)を参考にした案。KAKOUの構造は「小売の粗利を原資にした値引きでUGCと顧客囲い込みを買う」閉ループで、Artoirはそのまま真似できないが、**事業者のマーケ予算をArtoirユーザーへの特典に変換する中立プラットフォーム**の位置は取れる。クーポンは使われた分しか事業者コストが発生しない成果報酬型のため、協賛・広告(月数万PV待ち)と違い**現状の規模でも提携を持ちかけられる**。

候補として残す2案:

| 案 | 内容 | お金の流れ |
|----|------|-----------|
| 掲載特典クーポン | 展覧会を掲載した団体の部員全員に提携店(書道用品・画材)のクーポンを配布。サークル営業の口説き文句(「掲載すると部の画材費が浮く」)になる | 事業者の値引き原資 → 部員。Artoirの持ち出し・実装ほぼゼロ。償還実績が出たら送客手数料の交渉材料に |
| 展覧会ページ協賛枠 | 紙パンフレットの協賛広告慣行のオンライン版。ページ下部に「協賛: ○○」+来場者向けクーポン | 事業者の既存の協賛予算 → Artoir(掲載料)。「支出がすでに存在する」を通る |

- 掲載特典クーポンは秋の学祭営業(2026-11)までに1社確保が目標。候補: 書道用品店(書遊の競合)、世界堂・画箋堂など
- 協賛枠は展覧会数の実績ができてから。作品が映える世界観を壊さない控えめな表示が前提(`design.md`)
- 見送り: 図録×ネット印刷クーポン(図録生成の実装が重いため)
- **原則**: 特典は実在の展覧会・公募への参加に紐づけ、単純な投稿数・登録数に報酬を付けない(KAKOU型の低品質投稿リスクを避け、「芸術のアーカイブ」の建付けを守る)

### 検討した代替案の記録(2026-07)

アイデアの判定基準は4つ: **誰の財布か/その支出はすでに存在するか/Artoirの構造化データが手作業を肩代わりするか/「芸術のアーカイブ」という建付けに合うか**。

#### 将来の検討候補(時期尚早として保留)

| 案 | 内容 | 保留理由・再開条件 |
|----|------|-------------------|
| 貸しギャラリー提携 | ギャラリーが「展示プランにオンライン掲載ページ付き」を自分の客に売り、Artoirはギャラリーから月額/件数課金。図録の次のレバー筆頭 | 事業者相手なので月額が成立し、個人作家が自動流入する。ただし営業・信頼構築が必要。個人作家ユーザーが見え始めてから |
| 公募展・コンペのホスティング | 企業・自治体主催の公募展の応募受付+掲載+結果発表をパッケージ販売。主催者予算は大きい | 応募管理・審査機能などほぼ別プロダクトの開発が要る。美術・書道系コンペに限れば建付けに反しない |
| 印刷アフィリエイト | 図録PDFの入稿先(ラクスル等)の紹介プログラムを踏む | 単価は小さいが図録機能に乗せるだけ。図録実装時に追加 |
| 作品売買の仲介手数料 | 原画販売の10〜20% | 決済・配送・トラブル対応の信頼インフラが必要。個人作家が増えたフェーズの話 |
| 画材メーカー等の協賛・広告 | 美術系学生に届く媒体としての広告価値 | 月数万PV超えてから。今は時期尚早 |
| 助成金・学生起業支援 | 京大インキュベーション、文化系助成等でランニングコストを賄う | マネタイズではなく「つなぎ」。初期は現実的な選択肢 |

#### 見送り(理由つき)

| 案 | 見送り理由 |
|----|-----------|
| 主催者向け月額サブスク(旧方針: 月500円) | サークルは年1〜2回しか展覧会をせず月額は支出構造に合わない。転換率2〜5%では必要な母数(400〜2,000団体)が非現実的。「Webサービス月額費」という支出項目がサークル会計に存在しない |
| 広告用DM生成 | 1枚モノで載る情報が少なくCanvaで代替可能。Artoirの構造化データの優位性が出ない |
| 作品ポストカード(物販/主催者まとめ買い) | 使うデータが画像1枚でネット印刷直接入稿と大差ない。優位性が出ない |
| 学祭実行委への一括アーカイブ販売 | 実行委は予算を持つが、模擬店・技術展示等が混ざり「芸術のアーカイブ」の建付けに反する。学祭は広報の季節として使う(`marketing.md`) |
| 投げ銭 | 閲覧規模が小さいうちは決済手数料に食われる |
| OB/OG向けアーカイブ課金 | 支払い動線が複雑な割に単価が低い |
| 受託制作(ギャラリー特注サイト) | お金にはなるがプロダクトが進まず、学業との両立も苦しい |

### 未決事項

- **同意と作者名**: 図録(印刷・販売物)への利用は現行のオンライン公開同意と別途必要。また図録には作者名を載せる慣行があり、「作者名を作品に紐づけない」方針との整理が必要(「Webは匿名・図録は同意者のみ記名」等)。次回の出品調査アンケートまでに決める
- **画像解像度**: 印刷は300dpi必要。元画像を原寸でStorageに保持する方針の確認(現状はクライアントで長辺1920pxに圧縮 → `spec.md`)
- **収益の受け皿**: 受取名義(個人/任意団体)、特商法表記、チーム内の分配ルール
- **支払い手段**: 払うのはサークルの会計(部費)なので**領収書発行は必須**。可能なら請求書払い(Stripe invoice)も視野に
